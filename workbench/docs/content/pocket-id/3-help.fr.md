## Essayer une méthode alternative

Si vous ne parvenez pas à vous connecter à [Pocket ID](https://auth.terence.cloud) avec l'un de vos appareils, essayez d'abord sur tout vos autres appareils sur lesquels vous vous y êtes déjà connecté (autre téléphone, ordinateur, tablette...). Votre clé d'accès s'y trouve peut-être toujours.

Si c'est le cas:

1. Sur l'appareil qui a besoin de se connecter, à l'écran de connexion [Pocket ID](https://auth.terence.cloud), sélectionnez **Méthodes de connexion alternatives** en bas de la page.
2. Choisissez **Se connecter avec un autre appareil**.
3. Sur l'appareil déjà connecté :
   1. Scannez le code QR et approuvez la connexion.
   2. Ou alors visitez [auth.terence.cloud/device](https://auth.terence.cloud/device) et entrer le code affiché.

Votre appareil devrait désormais être connecté à nouveau.

> [!important]
> Une fois cela fait, **ajoutez tout de suite une nouvelle clé d'accès** en cliquant sur **Ajouter une clé d'accès**, sinon vous risquez d'être bloqué à nouveau.

Si cela ne fonctionne pas : contactez-moi. Je pourrai vous renvoyer un code de connexion et vous pourrez répéter les étapes de la phase [Enregistrer votre premier appareil](../1-enroll-first-device).
