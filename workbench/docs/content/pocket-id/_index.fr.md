Pocket ID ([https://auth.terence.cloud](https://auth.terence.cloud)) est le service de connexion pour tout ce qui se trouve sur terence.cloud. Un seul compte sur ce service vous permettra de vous connecter à tous les autres.

Il n'y a pas de mot de passe : chacun de vos appareils garde une **clé d'accès** (passkey), et vous confirmez avec votre empreinte, votre visage ou votre code PIN.

Pour commencer la première étape, vous devez avoir reçu un lien ou un code de connexion.
