Il est possible d'enregister autant d'appareils (tablette, ordinateur, autre téléphone...) que vous voulez.  Choisissez le cas qui correspond à votre appareil.

## Le même compte que votre premier appareil (le plus simple)

Si l'appareil est connecté au **même** compte iCloud, au **même** compte Google ou qu'il possède le même gestionnaire de mot de passe, votre clé d'accès devrait déjà y être. Pour le confirmer :

1. Ouvrez [auth.terence.cloud](https://auth.terence.cloud) dans **Chrome, Firefox ou Safari**.
2. Confirmez avec l'empreinte, le visage ou le code PIN que vous utilisez déjà sur cet appareil.

Si cela ne fonctionne pas, faites l'étape suivante.

## Un autre compte

Connectez-vous sur l'appareil avec le **code QR** :

1. Sur l'appareil, à l'écran de connexion Pocket ID, sélectionnez **Méthodes de connexion alternatives** en bas de la page.
2. Choisissez **Se connecter avec un autre appareil**.
3. Sur l'appareil déjà connecté :
   1. Scannez le code QR et approuvez la connexion.
   2. Ou alors visitez [auth.terence.cloud/device](https://auth.terence.cloud/device) et entrer le code affiché.

Cela vous connecte, **mais l'appareil n'a pas encore sa propre clé d'accès**. Une fois connecté, allez dans **Mon compte -> Clés d'accès -> Ajouter une clé d'accès** pour en enregistrer une directement sur l'appareil.

> [!tip]
> Posséder une clé par appareil est une configuration normale. En posséder plus d'une réduit les chances de perdre accès à votre compte Pocket ID.
